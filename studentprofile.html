DATABASE WEB DEVELOPMENT PROJECT

Student Profile System

A web-based student profile system created to collect, store and display student information in an organized and efficient way.

HTML CSS Bootstrap PHP MySQL React

About The Project

The Student Profile System is a database-driven web application developed to manage student information. It allows users to enter student details through a registration form and store the information in a MySQL database. The stored records can then be retrieved and displayed through the system.

Key Features

Student Registration

A structured form allows users to enter and submit student information. If any information is not included or correct it will be included there

Database Storage

Student information is stored in a MySQL database for easy management.

Student Records

Stored student information can be retrieved and displayed in an organized format.

Responsive Interface

The interface is designed to provide a good experience across different screen sizes.

How It Works

The user enters student information through the registration form. PHP processes the submitted information and communicates with the MySQL database to store the student's details. The stored information can then be retrieved from the database and displayed on the student records page or when needed to know how many students that filled it and collect their details.

My Contribution

I worked on the design and development of the student registration interface, connected the application to a MySQL database and worked on retrieving and displaying student records. The project also gave me practical experience working with PHP forms, database queries and dynamic web pages.

What I Learned

This project improved my understanding of PHP, MySQL and database management. I also gained practical experience with form handling, SQL queries, database connections and displaying information dynamically.
